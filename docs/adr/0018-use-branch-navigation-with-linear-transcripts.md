# Use branch navigation with linear transcripts

Interview Replay will render the lineage as a Branch Tree and show the selected branch as a linear Branch Transcript instead of making every message a structural tree node. Fork edges retain their source-message identity and every Forkable Message remains actionable in the transcript, while the branch-level tree stays readable across desktop, web, and mobile layouts even when conversations and branch counts grow. When a user forks from an inherited message, the child attaches to that message's Owning Branch rather than the currently focused descendant, so the tree represents the context actually inherited.
